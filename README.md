# Cafe Sales — Data Cleaning & Analysis

## Contexte

Analyse exploratoire d'un jeu de données de transactions de café
dans le cadre du challenge « Le Défi du Détective de Données ».

L'objectif est d'identifier les problèmes de qualité des données,
de nettoyer les données de manière raisonnée et d'en extraire
des insights non évidents.

## Contenu

- `dirty_cafe_sales.csv` : données originales, conservées intactes
- `cafe_sales_cleaned.csv` : données après nettoyage
- `notebook: cafe_sales_data_detective.ipynb` : analyse complète en Python/pandas
- `rapport detective Cafe Sales.pdf` : synthèse des résultats destinée au manager

## Méthodologie

1. Compréhension de la structure des données
2. Audit des valeurs manquantes et incohérentes
3. Nettoyage et conversion des types
4. Reconstruction des valeurs pouvant être déduites de manière fiable
5. Analyse exploratoire
6. Identification de trois insights principaux

## Outils

- Python
- pandas
- NumPy
- Matplotlib
